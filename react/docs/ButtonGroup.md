A set of related buttons arranged together with consistent spacing and a clear action hierarchy.

The Buttons group arranges related actions together as a single unit, keeping spacing, alignment, and hierarchy consistent so users can tell the primary action from its supporting ones. Instead of placing buttons manually, the component guarantees they read as a coherent set.

It can be laid out horizontally or vertically to fit the available space —vertical being especially useful on narrow or mobile layouts— and the secondary and tertiary buttons can be toggled on or off, so the group scales from a single primary action up to a full set of three. This makes it ideal for form footers, dialogs, and any place where actions live side by side.

## When to use
- Grouping the actions of a form, dialog, or card footer (e.g. Confirm + Cancel).
- Presenting a primary action alongside supporting ones with a consistent hierarchy.
- Layouts that need actions stacked vertically on narrow or mobile screens.
- Anywhere you want related buttons to keep uniform spacing and alignment automatically.

## When not to use
- For a single, isolated action — use a plain Button.
- Grouping unrelated actions that don't belong to the same decision.
- As a toolbar of icon buttons or a set of toggles (use the appropriate icon/toggle pattern).
- Choosing among mutually exclusive options — use Radio buttons or a segmented control.
- When actions belong in different areas of the screen rather than side by side.
