A set of related checkboxes arranged together under a shared label, for selecting several options at once.

The Checkbox group brings several related checkboxes together as a single, labeled unit, so users can read and select multiple options within one clear decision. It provides the structure and consistent spacing around the individual checkboxes, and a group label that names the choice they all belong to.

Because checkboxes are independent, the group is the right pattern whenever more than one option can be selected at the same time —filters, preferences, multi-select forms. Grouping them also improves scannability and makes the relationship between options explicit, rather than leaving them as loose, disconnected controls.

## When to use
- Presenting several related options where more than one can be selected.
- Filters, preferences, or multi-select sections in forms.
- Any group of choices that benefits from a shared label naming the decision.
- Keeping related checkboxes aligned and grouped instead of placed loosely.

## When not to use
- A single checkbox or opt-in — use the standalone Checkbox.
- Mutually exclusive choices where only one is valid — use a Radio buttons group.
- Settings that apply immediately on toggle — use Switches.
- Grouping unrelated options that don't share a common decision or label.
