A set of selectable pills for filtering or quick, related choices, with clear selected states.

A Pills group is a horizontal set of compact, selectable pills used for filtering content or making quick, mutually related choices. Because all options are visible at once, users can scan them and toggle a selection in a single tap, which makes pills ideal for lightweight filtering and category switching.

It is composed of individual Pill items, each with a clear selected state and the interaction range —default, hover, and disabled— so the current choice is unmistakable. The group scales from 1 to 10 items. Selection should be obvious and, depending on the use, allow one or several active pills; pills are not meant for primary page navigation.

## When to use
- Filtering content or switching between categories with all options visible.
- Quick, related choices users can toggle in a single tap.
- Sets of options that fit on screen and benefit from at-a-glance scanning (1–10 items).
- Lightweight selection where a clear selected state matters more than a full form control.

## When not to use
- Primary page navigation — use tabs or a menu.
- Formal single/multi selection in a form — use Radio buttons or a Checkbox group.
- Long option lists that don't fit on screen — use a Dropdown.
- Triggering actions — use a Button.
